# Blender 模型规范检查器 · 使用说明

> 适用版本：Blender 4.1 及以上（已在 **Blender 5.2.3 LTS** 实测通过）
> 配套文件：`asset_lint.py`（检查器）、`make_test_scene.py`（测试用例生成器）

---

## 一、最快用法（3 步）

1. 打开 Blender，顶部工作区标签点 **Scripting**
2. 点中间文本编辑器顶部的 **📂 Open**，选择 `asset_lint.py`
3. 点 **▶ Run Script**（或按 `Alt + P`）

然后切回 **Layout** 工作区，在 3D 视图里按 **N** 键，
右侧会多出一个 **「资产检查」** 标签页，点 **「运行模型检查」** 即可。

> 脚本运行后会立刻自动检查一次，报告路径会打印在下方的信息栏里。

---

## 二、报告在哪

默认输出到 **当前 .blend 文件所在目录** 下的 `_AssetLint` 文件夹：

```
你的项目/
├── 场景.blend
└── _AssetLint/
    ├── AssetLint_20261120_115440.csv    ← 可用 Excel 打开
    └── AssetLint_20261120_115440.html   ← 用浏览器打开，带颜色
```

如果 .blend 还没保存过，会输出到**桌面**的 `_AssetLint` 文件夹。

**HTML 报告**是给别人看的，**CSV 报告**是给自己存档、对比迭代用的。

---

## 三、检查哪些东西

| 检查项 | 默认规则 | 说明 |
|---|---|---|
| 命名 | 必须以 `SM_` 开头 | 前缀可在配置区改 |
| 命名 | 只允许字母/数字/下划线 | 中文、空格会被 UE 自动替换 |
| 面数 | 三角面 ≤ 50,000 | 按三角面算，不按四边面 |
| 几何 | 非流形边 | 3 个以上面共享的边 |
| 几何 | 重合面 / 游离顶点 / 退化面 | |
| 法线 | 封闭网格不允许整体反向 | 开放网格自动跳过 |
| UV | 必须有 UV、不重叠、不越界 | 重叠检测上限 2 万面 |
| 变换 | 缩放必须已应用，禁止负缩放 | |
| 材质 | 材质槽 ≤ 4 个，无空槽 | |

## 四、改规则

打开 `asset_lint.py`，找到文件顶部 **「规则配置区」**，是一段纯数字/文字配置：

```python
SCAN_MODE = "VISIBLE"        # 改成 "SELECTED" 只查选中的
MAX_TRIANGLES = 50000        # 角色资产可以改成 80000
MAX_MATERIAL_SLOTS = 4       # 移动端项目改成 2
NAME_PREFIX_RULES = ("SM_",) # 想同时允许 SK_ 就写 ("SM_", "SK_")
```

**不需要读懂下面的检查逻辑，改这几个数字就够了。**
改完重新 Run Script 生效。

---

## 五、命令行批量检查（不用开界面）

适合一次性检查一整个文件夹的模型，或者接到自动流程里：

```bash
blender --background 你的文件.blend --python asset_lint.py
```

报告会输出到 blend 同目录的 `_AssetLint`。

---

## 六、验证工具本身是否正常

运行测试用例生成器，它会造 10 个故意有问题的模型：

```bash
blender --background --python make_test_scene.py
```

预期结果：**共发现 16 条问题**，其中 `SM_GoodCube` 应该**零问题**。
如果数量和这个对不上，说明环境或脚本有问题。

## 七、常见问题

**Q：报告里的「疑似」是什么意思？**
A：检查器用的是几何启发式判断，不是绝对真理。
比如 UV 重叠，**镜像 UV 是正常做法**，会被报出来，需要人工确认。
所以叫「疑似」——工具负责筛出需要看的，人来拍板。

**Q：为什么我的球体报了 UV 重叠？**
A：Blender 的 Ico Sphere 默认 UV 本身就是重叠的（软件已知问题），不是误报。
需要重新展 UV。

**Q：改完模型要重新跑吗？**
A：要。检查器不记忆状态，每次都是全新扫描。好消息是 12 万面的场景只要 0.5 秒。
