# 3D 资产规范 v1.0

> **适用范围**：Blender / Maya 建模端 → UE5 引擎端
> **配套工具**：`blender/asset_lint.py`、`maya/asset_lint_maya.py`
> **一句话原则**：**问题发现得越早，返工越便宜。**
> 一条非流形边，在建模阶段修要 10 秒，进引擎后发现要重导、重做碰撞、重跑光照，可能要 30 分钟。

---

## 0. 为什么要有这份规范

美术做资产，往往是「做完一个交一个」。两个人做的两个箱子，命名不同、单位不同、UV 朝向不同，
到了引擎里就会出现：

- 材质引用找不到
- 尺寸忽大忽小
- 碰撞体和模型对不上
- 烘焙出来一块黑

这些问题的根源不是技术难度，而是**没有统一约定**。
这份规范把「大家心里都懂但不写下来」的约定固化，让检查工具能自动执行。

**每条规范都回答三个问题**：为什么要有、阈值是多少、不符合怎么修。

## 1. 命名规范

### 1.1 类型前缀

| 资产类型 | 前缀 | 示例 |
|---|---|---|
| 静态网格 | `SM_` | `SM_StreetLamp_01` |
| 骨骼网格 | `SK_` | `SK_Hero_Body` |
| 材质 | `M_` | `M_ToonBase` |
| 材质实例 | `MI_` | `MI_StreetLamp_Red` |
| 贴图 | `T_` | `T_StreetLamp_BaseColor` |
| 蓝图 | `BP_` | `BP_Door_Auto` |

**为什么**：引擎里所有资产混在同一个内容浏览器，前缀是唯一的快速识别方式。
按名字排序时，同类型资产会聚在一起，找东西快一个数量级。

**怎么修**：

- Blender：选中物体 → F2 改名
- Maya：选中物体 → 双击通道盒里的名字，或 `修改 → 重命名`

### 1.2 字符集

**规则**：只使用 `A-Z a-z 0-9 _`，**禁止**中文、空格、括号、连字符、`#`、`@`。

**为什么**：

- UE 的资产名只接受上述字符，中文和空格在导入时会被**自动替换**成下划线
- 替换后名字变了，材质引用、蓝图指针会断开
- 更有隐蔽的情况：替换后两个不同资产可能撞名

**实测**：Maya 甚至会直接拒绝创建中文名物体（报「无效的多字节字符」），
Blender 允许但导出后会变形。**早点拦住比事后找原因便宜。**

### 1.3 编号与变体

- 同类资产用两位数字后缀：`SM_Crate_01`、`SM_Crate_02`
- 变体用语义后缀而不是数字：`SM_Crate_Broken` 优于 `SM_Crate_03`
- LOD 用 `_LOD0`、`_LOD1`…（与 UE 自动识别规则一致）

## 2. 网格拓扑

### 2.1 非流形边

**规则**：不允许存在被 **3 个以上面**共享的边。

**为什么会出问题**：

- 布尔运算残留
- 两个物体合并后没有清理内部面
- 建模时误操作

进引擎后表现为：法线计算异常、碰撞体生成错误、光照漏光。

**怎么修**：

- Blender：编辑模式 → `选择 → 全部` → `网格 → 清理 → 删除松散几何`；
  再用 `选择 → 按特征全选 → 非流形` 定位后手动删面
- Maya：`网格 → 清理` 勾选「非流形几何体」

### 2.2 重合面（Lamina）

**规则**：不允许两个面**位置完全重合**。

**为什么**：z-fighting（两个面深度相同时闪烁）、烘焙出来是脏的、光照计算翻倍。

**怎么修**：

- Blender：`选择 → 按特征全选 → 内部面`，或合并重叠顶点（`M` → 按距离）
- Maya：`网格 → 清理` 勾选「Lamina 面」

> **注意**：polyUnite 会自动焊接重合顶点，所以合并两个重合物体后可能不报错——
> 这不代表没有重合面，只是被自动处理了。检查器按「顶点坐标」判断，能抓到没焊死的情况。

### 2.3 游离顶点

**规则**：不允许存在不属于任何面的顶点。

**为什么**：不参与渲染但会增大文件；某些引擎导入时会报错。

**怎么修**：Blender `网格 → 清理 → 删除松散点`；Maya `网格 → 清理` 勾选「孤立顶点」。

### 2.4 退化面

**规则**：面积接近 0 的面必须删除。

**为什么**：法线方向无法定义，渲染时可能黑面或闪烁。

**怎么修**：Blender `网格 → 清理 → 删除退化面`；Maya `网格 → 清理` 勾选「零面积面」。

## 3. 法线

**规则**：封闭网格的法线必须**全部朝外**。

**为什么**：法线反向会导致背面剔除（模型局部消失）、光照错误、碰撞体翻转。

**检测原理**：计算网格质心，统计「面法线指向质心」的比例，超过 30% 视为整体反向。
这个判据**只对封闭网格成立**——布料、外壳等开放网格的质心没有几何意义，工具会自动跳过并提示。

**怎么修**：

- Blender：编辑模式全选 → `Shift + N`（重新计算外侧）
- Maya：全选面 → `网格显示 → 反转法线`（如果整体反了）

**特殊原因**：**负缩放**会让模型看起来法线全反。先应用缩放再检查。

## 4. UV

### 4.1 必须有 UV

**规则**：所有进引擎的网格必须有 UV。

**隐藏陷阱**：Maya 中「UV 集还在、但 UV 数据被清空」是真实存在的状态
（比如执行过 `polyMapDel`、删面后重建）。**只看 UV 集数量会漏检，必须看 UV 坐标数量。**

### 4.2 不允许重叠

**规则**：除镜像 UV 外，不同面不能占用同一块 UV 空间。

**为什么**：烘焙法线/AO 时互相串色，贴图显示错误。

**怎么修**：

- Blender：在 UV 编辑器打开 `显示重叠 UV`（UV → Overlay → UV Stretch / 或插件 UV Toolkit）
- Maya：UV 编辑器 → 选择 → 选择重叠 UV

> **工具说明**：两个版本都使用自己实现的检测算法（空间哈希分桶 + 边相交/顶点包含）。
> 没有直接用 Maya 的 `polyUVOverlap`，因为实测它在「空间分离但 UV 完全重合」的模型上会漏检。

### 4.3 UV 必须在 0~1 内（除平铺贴图）

**为什么**：超出 0~1 的 UV 在 UE 中默认按平铺处理，如果贴图没有设置 `Wrap` 会出现接缝。

## 5. 变换

| 状态 | 规则 | 原因 |
|---|---|---|
| 缩放 | 必须为 (1,1,1) | 引擎里尺寸失真、UV 拉伸 |
| 旋转 | 建议归零 | 模型正面统一朝 +Y（UE 前向） |
| 负缩放 | **禁止** | 法线反向、碰撞体翻转 |

**怎么修**：

- Blender：`Ctrl + A` → 应用缩放 / 旋转
- Maya：`修改 → 冻结变换`

---

## 6. 材质

### 6.1 材质槽上限

**规则**：单个静态网格材质槽 ≤ **4 个**。

**为什么**：每个材质槽在引擎里是一次独立的 draw call。
移动端项目里，draw call 是最贵的资源之一。

**合并方法**：把多张小贴图打成图集（Atlas），用一个材质 + 不同 UV 区域。

### 6.2 不允许空材质槽 / 未赋材质的面

**为什么**：进引擎后显示默认白模，而且很难定位是哪几个面。

**检测注意**：Maya 的材质归属记录在 shadingEngine 的 sets 成员里，
面级 `listConnections` 查不到，而且 `sets()` 返回的是 **transform 名** 而不是 shape 名——
这是检查器里踩过的一个坑，写在这里提醒后来人。

## 7. 面数预算

面向《异环》这类**都市开放世界 + PC/移动双端**项目：

| 资产类型 | 三角面上限 | 说明 |
|---|---|---|
| 小道具（可拾取） | 2,000 | 数量多，必须省 |
| 街景道具（路灯/垃圾桶/长椅） | 8,000 | 会大量复制 |
| 建筑模块 | 15,000 | 模块化拼装，单个要克制 |
| 独立建筑/地标 | 50,000 | 视觉焦点可放宽 |
| 主角 | 80,000 | 面部与手部密度高 |

> 以上是**静态网格**的建模端预算。带 LOD 的资产，LOD0 按上表，LOD1 约 50%，LOD2 约 25%。

## 8. 导出前检查清单

把这份清单贴在工位上，或者直接跑检查器。

```
□ 命名前缀正确（SM_ / SK_ / M_ / T_）
□ 只用字母数字下划线，无中文/空格
□ 没有非流形边
□ 没有重合面
□ 没有游离顶点、退化面
□ 法线朝外
□ 有 UV，无重叠（镜像除外）
□ 缩放已应用，无负缩放
□ 材质槽 ≤ 4，无空槽
□ 三角面数在预算内
□ 构造历史已清理（Maya）
```

## 附录 A：常见错误对照

| 现象 | 最可能的原因 | 检查项 |
|---|---|---|
| 模型进引擎局部透明 | 法线反向 / 负缩放 | 法线、变换 |
| 烘焙出来有黑块 | UV 重叠 / 重合面 | UV、几何 |
| 贴图错位 | UV 越界 / 缩放未应用 | UV、变换 |
| 引擎里找不到材质 | 中文命名被替换 | 命名 |
| 碰撞体和模型对不上 | 负缩放 / 非流形 | 变换、几何 |
| 模型比别人大一圈 | 单位不一致 / 缩放未应用 | 变换 |

## 附录 B：修复顺序建议

检查器报出问题后，**按这个顺序修**，避免白干：

1. **先修几何**（非流形、重合面、退化面）—— 几何变了，UV 和法线都要重算
2. **再修 UV** —— 几何稳定后再展 UV
3. **修法线和变换** —— 应用缩放会让 UV 一起按比例变化
4. **最后修命名和材质** —— 这两项不影响前面

> 这个顺序本身就是经验。按错的顺序修，做完前三步还要回头重做。
