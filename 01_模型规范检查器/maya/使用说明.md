# Maya 模型规范检查器 · 使用说明

> 适用版本：Maya 2022 及以上（已在 **Maya 2022** 实测通过）
> 配套文件：`asset_lint_maya.py`（检查器）、`make_test_scene_maya.py`（测试用例生成器）

---

## 一、最快用法（4 步）

1. 打开 Maya，顶部菜单 **Windows → General Editors → Script Editor**
2. 在 Script Editor 里点 **File → Open Script**，选择 `asset_lint_maya.py`
3. 在脚本编辑区按 **Ctrl + A** 全选，再 **Ctrl + Enter** 执行
   （或点顶部工具栏的 ▶ 按钮）
4. 弹出一个「模型规范检查器」窗口，点 **「运行检查」**

---

## 二、报告在哪

默认输出到 **当前 .ma / .mb 文件所在目录** 下的 `_AssetLint` 文件夹：

```
你的项目/
├── 场景.ma
└── _AssetLint/
    ├── MayaAssetLint_20261120_115803.csv    ← Excel 可开
    └── MayaAssetLint_20261120_115803.html   ← 浏览器可开，带颜色
```

窗口里还有 **「打开报告文件夹」** 按钮，一点就弹出。场景没保存时输出到桌面的 `_AssetLint`。

## 三、检查哪些东西

| 检查项 | 默认规则 |
|---|---|
| 命名 | 必须以 `SM_` 开头；只允许字母/数字/下划线 |
| 面数 | 三角面 ≤ 50,000 |
| 几何 | 非流形边、边框边、**Lamina 重合面**、游离顶点 |
| 几何 | **构造历史未清理**（Maya 特有） |
| 法线 | 封闭网格不允许整体反向 |
| UV | 必须有 UV、不重叠、不越界 |
| 变换 | 缩放未冻结、负缩放、旋转未冻结 |
| 材质 | 材质槽 ≤ 4 个、未赋材质的面 |

## 四、Maya 独有的两个坑（面试可讲）

### 1. UV 集还在，但 UV 数据被清空

Maya 不允许删除默认 UV 集，但 `polyMapDel` 可以把 UV 数据删光。
此时 `polyUVSet -q` 仍然返回 `['map1']`，**看起来有 UV，实际上没有**。

检查器同时判断「UV 集数量」和「UV 坐标数量」，两个都查才抓得到。

### 2. 材质归属要解析 sets 成员

Maya 的材质不是挂在面上，而是记录在 **shadingEngine 的 sets 成员**里。
而且 `cmds.sets()` 返回的是 **transform 名**（如 `SM_Crate.f[0:1]`），
不是 shape 名——直接比较会全部误报成「没材质」。

检查器同时比对 shape 名和 transform 名，并把组件归一化后再算覆盖率。

## 五、改规则

打开 `asset_lint_maya.py`，找到文件顶部 **「规则配置区」**：

```python
SCAN_MODE = "VISIBLE"        # "SELECTED" 只查选中的
MAX_TRIANGLES = 50000        # 按三角面算
MAX_MATERIAL_SLOTS = 4
CHECK_HISTORY = True         # 是否检查构造历史
```

改完重新执行脚本生效。

## 六、命令行批量检查

不需要开 Maya 界面，用 `mayapy` 直接跑：

```bash
mayapy asset_lint_maya.py 你的场景.ma
```

适合批量检查所有待交付文件。`mayapy` 在 Maya 安装目录的 `bin` 下。

## 九、常见问题

**Q：为什么「构造历史未清理」总是报？**
A：Maya 的 `polyCube`、`polySphere` 等命令默认都会生成历史节点。
这是**正确提示**，导出前执行 `修改 → 冻结变换` 再手动删除历史即可。
如果嫌吵，把 `CHECK_HISTORY = False`。

**Q：检查很慢怎么办？**
A：大模型（3 万面以上）主要慢在 UV 重叠检测。
可以调小 `UV_OVERLAP_MAX_FACES`（比如 5000），超过就自动跳过并给提示。

**Q：可以检查多个选中的物体吗？**
A：可以。把 `SCAN_MODE = "SELECTED"`，然后在场景里选好再点运行。
