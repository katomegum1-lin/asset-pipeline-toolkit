# Maya → UE5 一键导出 · 使用说明

> 适用：Maya 2022+（已在 **Maya 2022** 实测）
> 文件：`ue_export_maya.py`

---

## 一、用法（3 步）

1. 在 Maya 里**选中**要导出的模型
2. **Windows → General Editors → Script Editor** → **File → Open Script** 打开 `ue_export_maya.py`
3. **Ctrl+A** 全选 → **Ctrl+Enter** 执行 → 弹窗里点 **「导出选中物体到 UE」**

导出文件在 **场景同目录的 `_UEExport`** 文件夹里。

---

## 二、它自动做了什么

| 步骤 | 说明 |
|---|---|
| 命名修正 | 非法字符 → 下划线；自动补 `SM_` 前缀 |
| 冻结变换 | 缩放/旋转/位移烘进顶点 |
| 删除构造历史 | 导出前自动清理 |
| 单位 | Maya 厘米 → UE 厘米，Scale Factor = 1.0 |
| 坐标轴 | 交给 FBX 标准转换，**不要手动旋转模型** |

**原场景不会被改。** 用的是 duplicate 出来的临时副本，导完自动删除。

---

## 三、常见问题

**Q：导入 UE 后模型大 100 倍 / 小 100 倍？**

改配置区的 `EXPORT_SCALE_FACTOR`：

- Maya 默认单位是**厘米**，UE 也是厘米 → 保持 `1.0`
- 如果你的场景单位被改成过米 → 可能需要 `100.0` 或 `0.01`

**Q：模型方向歪了？**

不要手动旋转模型。FBX 会做 Y-up → Z-up 的转换。
如果真歪了，检查建模时物体的朝向约定（UE 约定正面朝 +X）。

**Q：提示 FBX 插件加载失败？**

在 Maya 的 **Windows → Settings/Preferences → Plug-in Manager** 里，
勾选 `fbxmaya.mll` 的 **Loaded**。

**Q：中文名的物体导不出来？**

Maya 本身**拒绝创建中文名物体**（会报「无效的多字节字符」）。
如果是从其他软件导入的中文名模型，Maya 已经自动改成 `polySurface#` 了。
建议从一开始就用英文命名。

---

## 四、改配置

打开 `ue_export_maya.py` 顶部「配置区」：

```python
PREFIX = "SM_"              # 留空 = 不补前缀
DELETE_HISTORY = True       # 导出前删构造历史
EXPORT_SCALE_FACTOR = 1.0   # 单位换算
EXPORT_DIR = ""             # 指定输出目录，留空用默认
```

---

## 五、命令行批量导出

```bash
mayapy ue_export_maya.py 你的场景.ma
```

命令行模式会导出场景里**所有**网格物体（不需要手动选择），
适合一次性处理整个交付批次。

## 六、验证工具正常

```bash
mayapy make_export_test_maya.py
```

预期最后一行：`[结论] 全部检查通过：命名修正 ✓ 冻结变换 ✓ 尺寸正确 ✓ 原场景未改 ✓`

---

## 七、和检查器配合使用

推荐的工作顺序：

```
建模 → 跑检查器（修问题）→ 跑导出 → 拖进 UE
```

检查器负责「模型合不合格」，导出器负责「转换成引擎能吃的格式」。
两个都过一遍，基本不会出现「导入后才发现问题」的情况。
