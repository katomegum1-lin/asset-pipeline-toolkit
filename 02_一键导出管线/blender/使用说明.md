# Blender → UE5 一键导出 · 使用说明

> 适用：Blender 4.1+（已在 **5.2.3 LTS** 实测）
> 文件：`ue_export.py`

---

## 一、用法（3 步）

1. 在 Blender 里**选中**要导出的模型（可多选）
2. **Scripting** 工作区 → 打开 `ue_export.py` → **▶ Run Script**
3. 回 Layout，3D 视图按 **N** → 「UE 导出」→ **「导出选中到 UE」**

导出文件在 **blend 文件同目录的 `_UEExport`** 文件夹里，每个物体一个 FBX。

---

## 二、它自动做了什么

| 步骤 | 说明 |
|---|---|
| 命名修正 | 中文/空格/符号 → 下划线；自动补 `SM_` 前缀 |
| 应用变换 | 缩放、旋转、位移烘进顶点，导出的模型变换是单位值 |
| 坐标轴 | 转成 UE 的 Z 上 / -Y 前 |
| 单位 | Blender 米 → UE 厘米，缩放正确 |
| 碰撞体 | 场景里叫 `UCX_` + 模型名 的物体会自动一起导出 |

**原场景不会被改。** 导出用的是临时副本，导完自动删除。
所以你可以放心地对一个「还没有应用缩放、名字还是中文」的模型直接点导出。

---

## 三、导出后怎么进 UE

1. 打开 UE5，内容浏览器里建好目标文件夹
2. 把 `_UEExport` 里的 FBX **拖进内容浏览器**
3. 弹出的 FBX 导入选项里：
   - **Skeletal Mesh**：静态模型不要勾
   - **Generate Missing Collision**：如果模型自带 `UCX_` 碰撞体，UE 会自动识别
   - **Combine Meshes**：保持默认
   - **Import Uniform Scale**：**保持 1.0**（单位已经在导出时处理好了）

---

## 四、尺寸不对怎么办

如果导入 UE 后发现模型大了 100 倍或小了 100 倍，是**单位设置**的问题。

打开 `ue_export.py` 顶部配置区，改这一行：

```python
EXPORT_SCALE_OPTION = "FBX_SCALE_ALL"
```

四个选项的含义：

| 选项 | 什么时候用 |
|---|---|
| `FBX_SCALE_ALL` | **默认推荐**，把 Blender 场景单位完整写入 |
| `FBX_SCALE_UNITS` | 场景单位是「米」的标准情况 |
| `FBX_SCALE_NONE` | 不做单位换算，UE 里手动调 Import Uniform Scale |
| `FBX_SCALE_CUSTOM` | 配合 `global_scale` 手动指定倍数 |

**只需要改这一个参数，不用动其他代码。**

---

## 五、改配置

打开 `ue_export.py` 顶部「配置区」：

```python
PREFIX = "SM_"              # 不想自动加前缀就设成 ""
SANITIZE_NAMES = True       # 关掉就保留原始名字（不推荐）
SINGLE_FILE = False         # True = 多个物体合并成一个 FBX
EXPORT_DIR = ""             # 指定输出目录，留空用默认
```

---

## 六、命令行批量导出

```bash
blender --background 你的文件.blend --python ue_export.py
```

命令行模式下会导出场景里**所有选中的**物体。
如果需要全场景导出，先改 `export_selected()` 里的收集逻辑，或者做一个「全选」的包装脚本。

blender --background --python make_export_test.py

## 八、注意事项

- **中文名会丢信息**：「箱子 01」会被修正成 `SM_Asset_01`。
  工具会告警，但**建议你在建模阶段就用英文命名**，比事后猜哪个是哪个强。
- **碰撞体命名**：想在 UE 里自动生成精确碰撞体，在 Blender 里做碰撞模型，
  命名为 `UCX_加上模型名`（如 `UCX_SM_Crate_01`），导出时会自动带上。
- **材质**：FBX 只带材质名和基础颜色，贴图需要在 UE 里重新连。
  三渲二的材质节点本来就要在 UE 里搭，这一步省不掉。
